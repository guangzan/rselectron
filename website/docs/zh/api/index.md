# API

Rselectron 提供两个稳定面：

| 表面                               | 适用场景                                          | 页面                   |
| ---------------------------------- | ------------------------------------------------- | ---------------------- |
| [命令行界面](./cli)                | 终端工作流 — `dev`、`build`、`preview`、`inspect` | 命令与选项             |
| [JavaScript API](./javascript-api) | 程序化构建与开发                                  | ESM 导出与生命周期辅助 |

CLI 没有隐式默认命令。配置见 [配置](/config/)。
