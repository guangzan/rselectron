# 快速开始

:::tip 提示

本指南假设你熟悉 Electron 和 Rsbuild。开始前建议先阅读 [Electron 指南](https://www.electronjs.org/zh/docs/latest/) 和 [Rsbuild 指南](https://rsbuild.rs/zh/guide/start/)。

:::

## 总览

Rselectron 是面向 Electron 的构建工具，基于 Rsbuild，目标是更快、更简单的开发体验。它提供：

- 一套 `dev` / `build` / `preview` 命令，同时处理 Electron 的主进程（Node.js）与渲染进程（浏览器）环境。
- 为主进程、预加载脚本和渲染进程提供单一配置入口，并给出面向 Electron 的合理默认。
- 渲染进程支持模块热替换（HMR）；主进程与预加载脚本支持热重载。
- 基于 Rsbuild / Rspack；**不**生成安装包，也**不是**项目脚手架。

## 安装

:::tip 前提条件

Rselectron 需要 Node.js `>=20.19.0`，并安装 peer 依赖 `@rsbuild/core`（`^2.0.0`）。Electron 是可选 peer，需要启动应用时请装在项目根目录。支持的 Electron 版本见 [兼容性](./compatibility)。

:::

## 命令行界面

安装后可直接使用 `npx rselectron`，或在项目中调用已安装的 CLI：

### `rselectron dev`

构建主进程与预加载脚本，为渲染进程启动开发服务器，并启动 Electron。

### `rselectron build`

构建已配置的主进程、预加载脚本与渲染进程源码。通常在打包安装包之前执行。

### `rselectron preview`

构建（可用 `--skip-build` 跳过）并启动 Electron，用于预览生产构建。

### `rselectron inspect`

打印规范化后的配置，不构建也不启动。

更多选项见 [命令行界面](/api/cli)。

## 配置 Rselectron

运行 CLI 时，Rselectron 会解析项目根目录下的配置文件（如 `rselectron.config.ts`）。最基本的配置如下：

```ts title="rselectron.config.ts"
import { defineConfig } from 'electron-rstack';

export default defineConfig({
  main: {
    root: './src/main',
    source: { entry: { index: './index.ts' } },
  },
  preload: {
    root: './src/preload',
    source: { entry: { index: './index.ts' } },
  },
  renderer: {
    root: './src/renderer',
    source: { entry: { index: './index.ts' } },
  },
});
```

`main` / `preload` / `renderer` 各自是一份 Rsbuild 配置。仅在有意省略某一进程时才不要配置它。详情见 [配置](/config/)。

## Electron 入口

打包后，Electron 应用入口应指向**主进程构建产物**。在上面的最小配置下，默认输出在各进程 `root` 下的 `dist`，因此 `package.json` 可以是：

```json title="package.json"
{
  "name": "electron-app",
  "version": "1.0.0",
  "main": "./src/main/dist/index.js"
}
```

请保证 `main`（或配置里的 `electron.entry`）与主进程实际输出路径一致。你也可以像示例工程那样，通过 `output.distPath` 把产物集中到统一目录（例如 `out/main`）。

## 从示例开始

仓库提供可学习的示例（vanilla 与 React）：

- [`examples/vanilla`](https://github.com/guangzan/rselectron/tree/main/examples/vanilla)
- [`examples/react`](https://github.com/guangzan/rselectron/tree/main/examples/react)

复制示例目录，安装依赖后运行 `rselectron dev` 即可。
