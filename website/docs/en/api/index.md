# API

Rselectron exposes two stable surfaces:

| Surface                            | When to use                                               | Page                              |
| ---------------------------------- | --------------------------------------------------------- | --------------------------------- |
| [Command Line Interface](./cli)    | Terminal workflows — `dev`, `build`, `preview`, `inspect` | Commands and options              |
| [JavaScript API](./javascript-api) | Programmatic builds and development                       | ESM exports and lifecycle helpers |

The CLI has no implicit default command. Configuration: [Configuration](/config/).
